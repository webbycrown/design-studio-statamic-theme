Fold is a planning tool that had grown a second visual language for every feature. We designed a single density, a reserved accent, and empty states that teach instead of apologise.

The marketing site now uses the same components as the app, so a trial user is not dropped into a different world after signup.

We left a tokens file the engineers actually use. Pretty Figma that never ships is not a deliverable in this studio.
